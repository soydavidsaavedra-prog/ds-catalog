# DS Catalog - Project Context

## Vision

DS Catalog is a conversational commerce platform designed for businesses that sell primarily through WhatsApp.

The platform is mobile-first, scalable, reusable, and built as part of the DS Platform ecosystem.

---

## Project Goals

The MVP must allow businesses to:

- Publish products
- Search products
- Browse categories
- View product details
- Select variants
- Contact through WhatsApp

No authentication.
No shopping cart.
No online payments.

## Rules

Never hardcode colors.

Never duplicate components.

Always use TypeScript.

Always build reusable components.

Always prioritize mobile.

Never install unnecessary libraries.

Never generate code without explaining the changes first.
