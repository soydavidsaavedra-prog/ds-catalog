# Contexto del proyecto

**El Nuevo Sánchez** — fábrica y marca especialista en jeans. Slogan: "De la
fábrica a tus manos".

Este repositorio implementa la plataforma digital completa: home editorial,
catálogo (~200–300 productos previstos, ~36 de demo cargados), fichas de
producto con variantes (talla/color/disponibilidad), carrito con checkout
por WhatsApp, y panel administrativo (productos, categorías, banners,
pedidos, configuración) sin base de datos externa por ahora.

Para el detalle técnico completo — stack, arquitectura de datos, decisiones
y pendientes — ver `docs/ARCHITECTURE.md`. Para el estado fase por fase, ver
`docs/ROADMAP.md`.
